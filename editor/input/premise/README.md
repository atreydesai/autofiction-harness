# input/premise/

Drop the binding editorial standard documents here:

- Source premise file (e.g., `premise.txt`)
- `READING_GUIDE.md` — book-specific voice rules, register, motifs, form binding, length target, architecture questions
- Optional: calibration artifact (e.g., `register_calibration.md`) — observed drift from the drafting run, book-specific Gates, inviolable elements, optional amplification direction
- Optional: `reader_impressions.md` — author-direction reactions captured during drafting; treated as binding editorial direction

This directory in the shared package is empty by design — drop your own premise materials in.
