# input/artifacts/

Optional supporting artifacts from the drafting run (story_bible, continuity, skeleton, voice cards, tics tracker, etc.). The editor treats these as writer-intent evidence in Phase 2, not as authority.

Note: artifacts that prescribe specific chapter forms (e.g., chapter_cards labeling Ch N as "documentary") can bias the editor toward preserving those forms. Consider what you include here.

This directory in the shared package is empty by design — drop your own artifacts in.
