# input/draft/

Drop the drafted manuscript here as per-chapter Markdown files, one per chapter, named `chapter_01.md`, `chapter_02.md`, ... (the launcher's input validation only counts files matching `chapter_*.md` at this directory's top level). The editor will archive these to `output_edit/original_draft_archive/` before any edits.

This directory in the shared package is empty by design — drop your draft chapters in.
