# premise/

Drop your source premise here as a `.txt` or `.md` file. Optionally include a `READING_GUIDE.md` for book-specific voice rules, register, motifs, form binding, length target, etc. The reading guide overrides defaults in `long_novel_task.md` where they conflict.

If no reading guide is present, the agent derives one in Phase 1 and saves it as `output/reading_guide_derived.md`.

This directory in the shared package is empty by design — drop your own premise materials in.
