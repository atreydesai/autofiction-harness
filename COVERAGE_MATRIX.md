# Coverage Matrix — every source item, traced

This matrix maps **every entry** of the two check sources to its implementation in this harness:

- `unified_source_collation.md` (319 entries across 11 parts; collation of 17 sources) — Parts 1-3 below
- Wikipedia "Signs of AI writing" (WP:AIWTW; in-repo copy at `checks/sources/wikipedia_signs_of_ai_writing.md`) — Part 4 below

**Disposition vocabulary** (rows may combine with `+`):

| disposition | meaning |
|---|---|
| IMPLEMENTED-MECHANICAL | pattern registry row(s) in `checks/patterns/*.tsv`, enforced by `checks/quality_gate.py` |
| IMPLEMENTED-AUDIT | judgment audit template in `checks/audits/`, scheduled by `checks/audit_manifest.tsv` |
| IMPLEMENTED-PROTOCOL | process protocol in `checks/protocols/`, wired into the task prompts |
| IMPLEMENTED-SCAFFOLD | artifact template in `checks/scaffolds/`, required workspace state |
| IMPLEMENTED-PROMPT | woven into a stage task prompt (section named) |
| MERGED-WITH | de-duplicated into the named canonical entry/check (**the dedupe report**) |
| CANNOT-ADD | consciously excluded; reason in notes (**the cannot-add report**) |
| CAVEAT | meta/limitations commentary preserved in `CAVEATS.md` |

**Cannot-add summary.** The excluded items are exactly: the entire Publication part (manuscript-package/submission formatting, query letters/synopses/blurbs, traditional publishing/agents/scams/money flow/permissions, KDP/IngramSpark self-publishing production, hybrid-publishing due diligence, route comparison) — human business/market actions outside an autonomous drafting/editing harness; human-participant items (beta readers, critique groups, professional-editor hiring — their anti-sycophancy critique-calibration rules ARE implemented as the Critique stance header in every audit template); human writing-psychology items (daily routines, output math, block exercises — the relaunch/highest-leverage-next-action discipline is the harness analogue); software/tooling recommendations (Scrivener etc.); provenance/human-authorship adjudication; non-manuscript medium-routing rules (chat/web/docs/email formatting — manuscript-applicable parts merged into the formatting registry rows); external bibliographies; and two Wikipedia-only signs (list-title leads, WP:CONCRETE talk-page usage). Everything else is implemented or explicitly merged.
